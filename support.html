Woolnote 지원

자주 묻는 질문

단을 잘못 눌렀어요.
세는 화면의 한 단 빼기를 누르세요. 많이 틀렸으면 작품 수첩의 단 수 직접 고치기에서 숫자를 맞출 수 있습니다.

무늬가 몇 단째인지 따로 세고 싶어요.
작품 수첩의 카운터 더하기에서 무늬 반복을 고르고 몇 단마다 되풀이하는지 적으세요. 큰 버튼을 누를 때 함께 올라갑니다.

몇 단마다 코를 늘려야 하는데 자꾸 잊어요.
작품 수첩의 알림 더하기에서 처음 알릴 단과 몇 단마다인지 적으면, 그 단을 뜰 차례에 세는 화면에 표시됩니다.

도안은 어떻게 넣나요?
작품 수첩의 도안 칸에서 파일에서 가져오기나 사진 보관함에서 가져오기를 눌러, 가지고 있는 PDF나 사진을 고르세요. Woolnote는 도안을 제공하지 않습니다.

기기를 바꾸면 기록은 어떻게 되나요?
기록은 기기 안에만 있습니다. 설정의 백업 파일 만들기로 파일을 만든 뒤 새 기기에서 백업 파일에서 가져오기를 누르세요. 사진과 도안 파일은 백업에 들어가지 않습니다.

Woolnote Support

Frequently asked questions

I tapped by mistake.
Tap Undo row on the counter. If the count is far off, open the project notebook and use Set the row count.

I want to track where I am in a pattern repeat.
In the project notebook, tap Add a counter, choose Pattern repeat and enter how many rows the repeat has. It counts along with the big button.

I keep forgetting to increase every few rows.
In the project notebook, tap Add a reminder and enter the first row and how often it repeats. The counter shows it when that row is next.

How do I add a pattern?
In the project notebook, under Pattern, tap Import from Files or Import from Photos and pick a PDF or photo you own. Woolnote does not provide patterns.

What happens to my projects when I change devices?
Projects are stored only on the device. Create a backup file in Settings, then use Restore from a backup file on the new device. Photos and pattern files are not included in the backup.
